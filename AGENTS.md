# Fresh Start project workflow

- GitHub repository: `https://github.com/bequettebrystol-oss/Fresh-Start-Roblox-Simulator.git`.
- After every completed project change, update `Project Notes.md` with what changed, why, and any validation performed.
- Commit and push each completed change together with its updated notes to the user's designated GitHub repository. The user has explicitly authorized this ongoing workflow.
- Include reviewable game source or project files for Roblox Studio changes; notes alone are not a backup of the game.
- If the repository, authentication, or source synchronization is unavailable, preserve the work locally and clearly report what has not been pushed. Never claim a successful push without verifying it.
- Do not publish unrelated vault settings or personal files.
